
# Accessibility Report

**Author:** Anthony Mugwe  
**Project:** Week 1 Multi-Page Portfolio  
**Course:** IYF Wecan Academy Season 12

## 1. Objective

The purpose of this report is to evaluate the accessibility of my portfolio and document improvements made during development.

## 2. Testing Method

Tool: Google Lighthouse

Pages tested:
- index.html
- about.html
- projects.html
- contact.html

Test environment:
- Browser: Chrome browser 
- Device: phone 
- Website URL: https://novelfire.net

## 3. Before Improvements

Accessibility score before improvements: 100/100

## 4. Lessons Learned

I learned that accessibility requires meaningful HTML structure, descriptive labels, suitable alternative text, and careful testing. Lighthouse helps identify potential issues, but manual keyboard and screen-reader checks are also useful.

## 5. Conclusion

I used Lighthouse to assess the deployed portfolio and documented the measured scores and changes made. I will continue testing and improving accessibility as I develop more websites.
