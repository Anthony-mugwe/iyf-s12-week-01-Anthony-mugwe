## Lessons Learned

During this project I learned how to create a multi-page website using HTML and CSS.

I learned how HTML elements are structured using the `html`, `head` and `body` elements.

I also learned how semantic HTML elements such as `header`, `nav`, `main`, `article`, `section`, `aside` and `footer` improve the structure and meaning of a webpage.

Another important lesson was accessibility. I learned how to connect labels to form controls using the `for` and `id` attributes, how to use `fieldset` and `legend`, and why images need useful alternative text.

I also learned how to create a GitHub repository, make commits, push files to GitHub and deploy a website using GitHub Pages.

---

## Challenges Faced

One challenge I faced was understanding how multiple HTML pages connect to each other. I solved this by using relative links such as `about.html`, `projects.html` and `contact.html`.

Another challenge was creating an accessible contact form. I learned that every form control should have a meaningful label and that the label must be connected to the correct input.

I also had to learn how Git tracks changes and how commits are used to save project progress.

Deploying the website with GitHub Pages was another learning experience because the file names and folder structure had to be correct.
